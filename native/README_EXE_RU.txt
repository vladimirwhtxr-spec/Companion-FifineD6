D6NativeBridge.exe — экспериментальная сборка Windows x64

Python и зависимости включены внутрь EXE. Распакуйте архив в папку с правом
записи. Запустите EXE: откроется меню.

1 — проверка виртуального драйвера без открытия D6 (90 секунд).
2 — калибровка экранов физического D6. Закройте FIFINE/Companion/старые мосты.
3 — мост между виртуальным драйвером и D6.
4 — проверка упакованных компонентов, не проверка распознавания в Elgato.
0 — выход.

Существующий screen_map.json положите РЯДОМ с EXE. Там же создаётся журнал
native_bridge.log. Для режимов 1 и 3 драйвер разрешает доступ только
администраторам: после его установки запускайте эти режимы от администратора.

ВАЖНО: этот EXE сам по себе не добавляет устройство в Elgato Stream Deck.
Нужен ещё драйвер D6VirtualDeck.sys с подходящей подписью. В этот архив драйвер
не включён. При его отсутствии режимы 1/3 сообщат об ошибке открытия устройства.
Совместимость с Stream Deck 7.6.0 не подтверждена на реальном компьютере.
Это не установщик, не Companion-мост и не стабильный релиз.

EXE не подписан сертификатом издателя. Проверка компонентов запускается на
Windows в сборочном процессе; тесты не подключают физический D6.
Программа не меняет прошивку, Secure Boot, настройки подписи или автозапуск.

Командная строка:
D6NativeBridge.exe --self-test
D6NativeBridge.exe --probe --seconds 90
D6NativeBridge.exe --calibrate

Исходники драйвера и инструкция его сборки находятся в native/driver и
native/README_RU.md в отдельной ветке build/native-exe-20260928 репозитория
https://github.com/vladimirwhtxr-spec/Companion-FifineD6
