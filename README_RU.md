# FIFINE D6 → Companion: инструкция на русском

[English](README_EN.md) · [Главная](README.md)

Версия **0.4.1-rc.1 — кандидат в релиз**. Проверка трея Windows и полного обмена
с физическим D6 ещё нужна. Специальный драйвер, перепрошивка и программа Elgato
для этого моста не требуются.

## Требования

- Windows и Python 3.12+. Установщик использует `py`, затем `python`, если `py`
  отсутствует. Старую версию Python в `.venv` установщик отклонит.
- FIFINE D6 с USB VID `3142`, PID `0060`.
- Bitfocus Companion с Satellite API 1.9+. Целевая установка пользователя —
  Companion 5.0.5; совместимость со всеми версиями не подтверждена.
- Папка с правом записи; интернет нужен для первоначальной установки зависимостей.

## Установка и обновление

1. Закрой старый мост и родную программу FIFINE.
2. Скачай проект через **Code → Download ZIP**, полностью распакуй архив.
3. Запусти `01_install.cmd`: зависимости установятся в `.venv` внутри папки.
4. При обновлении перенеси из предыдущей версии **`screen_map.json` и свой
   `config.json`, если он был**. Старую `.venv` переносить не нужно.
   Проверенную карту экранов можно использовать без повторной калибровки.
5. Для новой установки запусти `02_calibrate.cmd` по инструкции ниже.
6. Запусти Companion, затем **`03_companion.vbs`** — без окна консоли.
   Альтернатива: `03_companion.cmd`, его окно запуска сразу закроется.
   Если VBScript отключён в Windows, используй CMD.

Права администратора не нужны. Автозапуск Windows не устанавливается.
Храни распакованную папку в постоянном месте.

## Калибровка

Порядок кодов кнопок отличается от порядка адресов экранов. Не подставляй карту
наугад. До общей калибровки отдельно подтверждено только соответствие:
адрес экрана 5 → нижняя правая кнопка, входной код 15.

Запусти `02_calibrate.cmd`. На D6 должны появиться числа 1–15. По очереди нажимай
**и отпускай кнопку D6, на которой написано запрошенное число**. Это не клавиша
клавиатуры компьютера. Если цифры отсутствуют или накладываются, останови
калибровку через Ctrl+C; предыдущая карта останется.

В конце проверь порядок чисел: 1–5, 6–10, 11–15, слева направо и сверху вниз.
Введи `YES` на компьютере, чтобы сохранить `screen_map.json`.

## Подключение к Companion

По умолчанию используется `127.0.0.1:16622`. В Companion должен быть включён и
доступен сервис Satellite. Его TCP-порт отличается от порта веб-интерфейса.

Если Companion на другом компьютере или порту, скопируй `config.example.json`
в `config.json` и укажи адрес:

```json
{"host": "127.0.0.1", "port": 16622}
```

В `host` нужен адрес компьютера с Companion. При необходимости разреши входящее
TCP-соединение в его брандмауэре. Мост не добавляет шифрование или аутентификацию;
используй доверенную сеть. После правки настроек выключи и включи мост через трей.

В **Companion → Surfaces** найди **FIFINE D6 Bridge**, назначь страницу и действия
кнопкам. Зелёный значок означает подтверждённую регистрацию поверхности;
отдельно проверь действие кнопки и обновление картинки.

## Управление через трей

Нажми правой кнопкой на значок D6 возле часов. Если его не видно, открой стрелку
скрытых значков Windows.

| Команда | Действие |
| --- | --- |
| Включить | Открывает D6 и подключается к Companion |
| Выключить | Отпускает кнопки, удаляет поверхность из соединения, закрывает USB/TCP; значок остаётся |
| Выход | Останавливает мост и убирает значок |
| Открыть журнал | Открывает журнал обмена с D6/Companion |
| Журнал запуска и трея | Показывает ошибки запуска и интерфейса |
| Открыть папку | Открывает папку программы |

Зелёный — зарегистрирован; жёлтый — запуск/соединение/ожидание/остановка;
серый — выключен; красный — ошибка. При запуске программы мост включается сразу.
Повторный экземпляр трея в той же сессии Windows блокируется. Старую консольную
версию и программу FIFINE всё равно нужно закрыть отдельно.

## Решение проблем

- **Красный значок:** открой оба журнала. Без `screen_map.json` нужна калибровка;
  при отсутствии Python-модуля повтори `01_install.cmd`.
- **Companion недоступен:** проверь Satellite, адрес, порт и брандмауэр.
  Переподключение автоматическое. Нажатия вне подключения не воспроизводятся позже.
- **Отключился USB:** подключи D6, закрой конкурирующие программы и нажми «Включить».
- **Картинка осталась после выключения:** экран может сохранять последний кадр
  после закрытия USB; это не означает, что мост продолжает работать.
- **Остановка задерживается:** дай процессу восемь секунд. Зависший процесс
  завершается принудительно; доставка отпусканий кнопок в этом случае не гарантирована.
- **Редактирование JSON:** поддерживается UTF-8 с BOM и без BOM; синтаксис должен
  оставаться корректным.

Журналы ограничены по размеру: мост — 2 МБ и три резервные копии, трей — 1 МБ
и две копии. Перед отправкой проверь содержимое: там могут быть адрес Companion
и локальные пути.

## Удаление и проверка

Выбери «Выход» и удали распакованную папку. Системная служба, драйвер и
автозапуск не устанавливались.

Автоматические тесты: `.venv\Scripts\python.exe -m unittest discover -v`.
Перед стабильным релизом выполни [проверку на устройстве](RELEASE_CHECKLIST.md).
