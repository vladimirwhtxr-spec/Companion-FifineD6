# D6 Companion Bridge — Windows x64

Мост FIFINE AmpliGame D6 ↔ Bitfocus Companion 5.0.5 по Satellite API 1.9+.
Elgato Stream Deck и драйвер D6VirtualDeck не используются. Python уже включён.

## Первый запуск

1. Распакуйте весь ZIP в отдельную папку с правом записи, например `Документы\D6Companion`. Не запускайте из ZIP. Оставьте оба EXE в одной папке.
2. Закройте фирменную программу FIFINE и другие мосты, использующие D6. Подключите D6 по USB.
3. Если есть рабочий `screen_map.json` от прежнего Companion-моста, скопируйте его рядом с EXE. Иначе запустите `D6Tools.exe`, выберите `1` и выполните калибровку: нажимайте и отпускайте на D6 кнопку с запрошенным числом. В конце подтвердите правильную сетку 3×5 вводом `YES` на клавиатуре компьютера. При наложении/отсутствии чисел остановите калибровку; не подтверждайте неправильную сетку.
4. Запустите Companion и включите его Satellite listener на TCP 16622. По умолчанию мост подключается к `127.0.0.1:16622`. Если Companion на другом ПК или порту, скопируйте `config.example.json` в `config.json`, измените `host`/`port` и перезапустите мост через трей.
5. Запустите `D6Companion.exe`. Окна консоли не будет: найдите значок D6 возле часов, при необходимости раскройте скрытые значки.
6. При наличии карты экранов мост включается автоматически. В Companion откройте Surfaces и настройте появившуюся поверхность `FIFINE D6 Bridge`.

## Меню значка D6

- **Включить** — запустить мост, в том числе повторить запуск после ошибки.
- **Выключить** — остановить мост и освободить USB, оставив значок в трее.
- **Открыть журнал** — ошибки и обмен с Companion.
- **Журнал запуска и трея** — проблемы запуска дочернего процесса.
- **Открыть папку** — настройки, карта экранов и журналы.
- **Выход** — остановить мост и полностью закрыть приложение.

Зелёный индикатор означает регистрацию в Companion, жёлтый — подключение/ожидание, серый — выключен, красный — ошибка. Повторный запуск приложения не создаёт второй мост.
Перед новой калибровкой выберите **Выход** в трее. Не запускайте два экземпляра калибровки.

## Диагностика

`D6Tools.exe`, пункт `2`, проверяет встроенные компоненты без проверки физического D6.
`D6Tools.exe --self-test` выполняет ту же проверку из командной строки.
При ошибке USB закройте другие программы D6, переподключите устройство и выберите **Включить**.
При разрыве TCP мост повторяет подключение. Нажатия во время разрыва не воспроизводятся после подключения.
Данные: `screen_map.json`, `config.json`, `d6_bridge.log`, `d6_tray.log` рядом с EXE. Для сохранения настроек при обновлении заменяйте только EXE и документацию.
Автозапуск Windows не настраивается автоматически. Приложение не требует прав администратора.

## Статус проверки

Это сборка для проверки на устройстве, не подтверждённый эфирный релиз. Автотесты проверяют протокол, остановку/перезапуск процессов и освобождение USB с имитацией устройства; сборка Windows дополнительно запускает оба EXE. Физического D6 на сервере сборки нет. Проверка реальных кнопок, картинок и длительной работы с Companion 5.0.5 остаётся необходимой.
EXE не подписаны сертификатом издателя. Исходники и сборка: ветка `build/companion-exe-20260928` в https://github.com/vladimirwhtxr-spec/Companion-FifineD6.
